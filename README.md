# Claude Agent Hub

tmux 上で複数の Claude Code セッションを起動し、ブラウザから状態の確認・切り替え・対話を行うローカルハブです。
状態の判定は画面のスクレイピングではなく、Claude Code の **hooks** から届くイベントを基にしています。

## 主な機能

- ブラウザからのエージェント（Claude Code セッション）の作成・再起動・終了・削除・エフォートの変更と、状態（実行中・要対応・応答完了など）の一覧表示
- 会話の表示（Markdown・mermaid 図、エージェントが読んだ画像や貼り付けた画像のサムネイル、時刻と応答の所要時間に対応）と、tmux 画面のスナップショット表示
- 質問・計画の承認・権限の確認・MCP の入力要求への、ブラウザからの回答
- 今すぐ送る送信と、作業が終わるたびに順に送るタスクキュー
- Claude が示した複数の提案を「採用 / 却下 / 修正して実施」に仕分けて返答する仕分けボード
- エージェントが起動したサブエージェントの、一覧へのツリー表示（状態を示す小さい猫付き）と会話の表示
- コンテキスト量の表示（目安を超えると「切り替え推奨」の目印）と、引き継ぎメモを作ってから `/clear` して新しいセッションで再開する「引き継いでリセット」
- Claude の利用上限（5 時間の枠と週の枠）の使用率のバー表示
- 状態に合わせて動くドット絵の猫、tmux のステータス行の色分け、デスクトップ通知

各機能の詳しい使い方は [docs/usage.md](docs/usage.md) を参照してください。

## 必要なもの

- Node.js 20 以上（外部パッケージは不要）
- tmux 3.0 以上
- Claude Code（`claude` コマンド）

## 起動

```bash
npm start
# → http://localhost:4317
```

1. ブラウザで `http://localhost:4317` を開き、左上の「＋ 新規」からエージェントを作成します。作業ディレクトリを空欄にすると、リポジトリ直下の `workspaces/` の下に作ります。
2. 初めて使うディレクトリでは Claude Code の信頼確認ダイアログが表示されます。「ターミナル」タブで画面を確認し、キー送信ボタン（Enter など）で応答してください。
3. エージェントは tmux セッション `agent-hub` の各ウィンドウで動きます。端末から直接操作する場合は `tmux attach -t agent-hub` を実行してください。

ポート・tmux セッション名・データの保存先などは環境変数で変更できます（[設定](docs/configuration.md)）。

## 重要な注意

- **認証はありません。** サーバは `127.0.0.1` でだけ待ち受けますが、同じマシンのほかの利用者やプロセスからは接続でき、エージェントへの指示の送信や権限確認への回答（コマンド実行の許可）ができます。共有のマシンでは使わず、ポート転送やリバースプロキシで外部に公開しないでください。
- **放置してもトークンを消費し続けることがあります。** タスクキューは、作業が終わるたびに次の項目を自動で送信します。権限モードを auto にしたエージェントや、計画を「承認（auto モードで実行）」で承認したセッションは、確認なしでツールを実行します。席を離れるときはキューを一時停止してください。
- **「許可して記憶」はハブの外のセッションにも効くことがあります。** 選んだルールの保存先が「このセッション」以外（ローカル設定・プロジェクト設定・ユーザー設定）の場合、Claude Code が設定ファイル（作業ディレクトリの `.claude/settings.local.json`・`.claude/settings.json`、`~/.claude/settings.json`）に書き込むため、同じディレクトリなどで直接起動したセッションにも適用されます。候補は最初からすべて選ばれているので、カードに表示される保存先を確かめてから選んでください。
- **「削除」は作業中でもセッションを終了します。** tmux のウィンドウを閉じ、ハブのイベント記録も消します。作業ディレクトリと Claude Code の会話記録は残ります。tmux セッション `agent-hub` を終了した場合も、すべてのエージェントが終了します。
- tmux 側で直接 Esc / Ctrl+C を押して中断すると、状態が「実行中」のまま残り、キューが送信されないことがあります。中断はハブのキー送信ボタンから行ってください（[既知の制約](docs/usage.md#既知の制約)）。
